Coolify on Hetzner — outline

  1. Create or use a VPS (e.g. Hetzner CX21), install Coolify per Coolify docs.
  2. In Coolify, add a New Resource → Dockerfile (or Git-based build) pointing at this repository’s main branch and root Dockerfile.
  3. Set Build pack / context to the repo root; no compose required (NFR-001).
  4. Expose port 8080 (or map Coolify’s detected port to the container’s PORT — the image defaults to 8080).
  5. Add environment variable FLASK_SECRET_KEY with a long random string (generate locally; do not commit it).
  6. Deploy, open the HTTPS URL Coolify assigns, upload a test CSV, and confirm lists and bubbles work and no buy prices appear.

Detailed notes for operators: docs/deploy/coolify-hetzner.md in the repository.
